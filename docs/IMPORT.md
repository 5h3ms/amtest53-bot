# Добавление слов из таблиц

Исходные Excel-файлы и промежуточные выгрузки храните в `private-materials/`. Этот каталог и файлы `.xlsx`/`.xls` исключены из Git. В публичный курс попадают только проверенные армянские слова, русские переводы, категория и ссылка на лист/строку источника. Имена авторов, свойства файлов, пути и транскрипция не импортируются.

Таблицы сначала нужно разобрать по их фактической структуре: в исходных файлах есть несколько блоков на одном листе, обратный порядок языков и сочетания двух языков в одной ячейке. Автоматически считать любые два соседних столбца словарём нельзя. Спряжения, правила, неполные строки и неоднозначные пары остаются на ручной проверке.

После проверки подготовьте JSON-массив следующего вида:

```json
[
  {
    "hy": "տուն",
    "ru": "дом",
    "category": "nouns",
    "source": { "workbook": "nouns", "sheet": "Сущ. ", "row": 2 }
  }
]
```

Категории: `nouns`, `verbs`, `other`. Поле `workbook` — условное имя одного из двух исходных словарей: `nouns` или `verbs`. Пример показывает формат; при импорте указывайте реальные значения и координаты. Одна запись может содержать слово, устойчивое выражение или несколько форм из одной ячейки.

```powershell
npm run content:import -- private-materials/import-ready-vocabulary.json 2026-10-28.authored_training.user_vocab.v2
npm run check
npm run build
```

Импорт проверяет записи перед записью файла, объединяет одинаковые армянские заголовки и сохраняет разные русские значения через точку с запятой. Повторный запуск с тем же входным файлом не дублирует карточки, источники или уроки. Исходные учебные ID сохраняются; новые зависят от армянского заголовка. Слова группируются в уроки по десять, без добавления вымышленных экзаменационных вопросов.

Проверяйте итоговый `git diff` и учебные формулировки перед коммитом. Исправления в переводах должны быть осознанными и отмеченными в источниках курса. Изменение написания армянского заголовка может создать новый ID: при таком исправлении отдельно проверьте старую карточку и её прогресс. Удаление устаревших слов не выполняется импортом автоматически.
